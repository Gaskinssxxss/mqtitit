CARA RUNNING MUDAH KONSEP LAMA
==============================

Cara paling mudah untuk konsep lama adalah memakai:

./run_all_cli.sh

Script ini akan menanyakan:

1. IP broker MQTT.
2. Interface jaringan PC A.
3. Port MQTT yang akan diamati.

Setelah itu, script menjalankan sniffer dan prober secara otomatis.


1. CONTOH KONFIGURASI
---------------------

IP broker MQTT:

192.168.100.50

Interface PC A:

eth0

Port MQTT:

1883


2. JALANKAN
-----------

./run_all_cli.sh

Jika ingin langsung memakai nilai dari lab_env.sh:

./run_all.sh


3. SAAT EKSPERIMEN BERJALAN
---------------------------

Program yang berjalan:

1. sniffer_capture.sh
   Menangkap trafik MQTT dengan tshark.

2. mqtt_prober.sh
   Mengirim pesan MQTT normal ke broker setiap 1 detik.


4. MENGHENTIKAN EKSPERIMEN
--------------------------

Tekan:

CTRL+C

Setelah itu run_all.sh akan:

1. menghentikan sniffer dan prober;
2. mencari file pcap terbaru;
3. menjalankan extract_raw_flow.sh;
4. membuat file raw_flow.csv.


5. HITUNG METRIK
----------------

Jalankan:

python3 compile.py pcap/NAMA_FILE_raw_flow.csv -o metrics.csv --ports 1883


6. FOLDER OUTPUT
----------------

logs/
    Log pengiriman MQTT normal dari mqtt_prober.sh.

pcap/
    File capture pcapng dan raw_flow.csv.

metrics.csv
    File metrik hasil compile.py.


7. HAL YANG HARUS DIINGAT
-------------------------

- PC A adalah host monitoring.
- Broker MQTT adalah target.
- Attacker dijalankan dari mesin lain saat skenario DoS.
- Capture hanya merekam trafik yang terlihat pada interface PC A.
- Jika trafik attacker tidak melewati PC A, data serangan bisa tidak terlihat
  lengkap.
