01_windows_client
-----------------

Folder ini hanya untuk Windows. Tidak membutuhkan WSL. Program PowerShell
menjalankan client Python dan proses analisis. Hasil akhir seluruh mesin
dikumpulkan di folder experiments pada bagian ini.

02_ubuntu_server_a_broker
-------------------------

Folder ini hanya untuk VirtualBox A. Broker Mosquitto berjalan pada mesin ini.
TShark merekam paket pada interface jaringan Ubuntu Server A dan nftables
menjalankan rate limiting pada skenario mitigasi.

03_ubuntu_server_b_attacker
---------------------------

Folder ini hanya untuk VirtualBox B. Hping3 menghasilkan SYN flood menuju IP
Ubuntu Server A. Folder ini tidak dibutuhkan oleh Windows atau broker.

Mengapa kode dipisahkan?
------------------------

Setiap mesin hanya melihat program yang menjadi tanggung jawabnya. Dengan
demikian, pengguna tidak perlu memilih role broker/client/attacker dari satu
script campuran dan risiko menjalankan program pada mesin yang salah berkurang.
