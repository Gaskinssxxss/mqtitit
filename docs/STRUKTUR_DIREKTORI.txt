STRUKTUR DIREKTORI KONSEP LAMA
==============================

Project utama sekarang memakai konsep sniffer dan prober.

Struktur utama:

.
├── lab_env.sh
├── run_all.sh
├── run_all_cli.sh
├── sniffer_capture.sh
├── mqtt_prober.sh
├── extract_raw_flow.sh
├── compile.py
├── requirements.txt
├── docs/
└── tmp/


PENJELASAN FILE
---------------

1. lab_env.sh

   File konfigurasi utama. Isinya:

   - TARGET_IP: alamat IP broker MQTT.
   - MQTT_PORTS: port MQTT yang diamati, misalnya 1883.
   - NET_IFACE: interface jaringan pada PC A.
   - LOG_DIR: folder log prober.
   - PCAP_DIR: folder hasil capture.

2. run_all.sh

   Script orkestrasi. Script ini menjalankan:

   - sniffer_capture.sh
   - mqtt_prober.sh

   Keduanya berjalan bersamaan sampai user menekan CTRL+C.

3. run_all_cli.sh

   Versi interaktif dari run_all.sh. User dapat mengisi IP broker, interface,
   dan port MQTT sebelum eksperimen dimulai.

4. sniffer_capture.sh

   Script untuk capture paket jaringan menggunakan tshark. Output-nya adalah
   file pcapng di folder pcap/.

5. mqtt_prober.sh

   Script untuk mengirim pesan MQTT normal ke broker menggunakan mosquitto_pub.
   Output-nya adalah CSV log di folder logs/.

6. extract_raw_flow.sh

   Script untuk mengubah file pcapng menjadi CSV raw flow.

7. compile.py

   Script Python untuk menghitung metrik trafik dari raw_flow.csv.
