TUTORIAL SETUP DAN PENGUJIAN END TO END
KONSEP LAMA: HOST MONITORING + SNIFFER + PROBER
================================================

Arsitektur:

PC A / host monitoring
├── sniffer_capture.sh
├── mqtt_prober.sh
└── run_all.sh

Broker MQTT
└── target layanan MQTT

Attacker
└── mesin lain yang mengirim serangan saat skenario DoS


1. SETUP PC A
-------------

Install dependency:

sudo apt update
sudo apt install -y tshark mosquitto-clients python3 python3-pip
python3 -m pip install -r requirements.txt

Set executable:

chmod +x *.sh


2. SETUP BROKER MQTT
--------------------

Broker MQTT dapat berada pada server terpisah.

Yang perlu diketahui oleh PC A:

- IP broker MQTT;
- port MQTT;
- jalur/interface jaringan yang bisa diamati PC A.

Contoh:

IP broker MQTT: 192.168.100.50
Port MQTT: 1883


3. SETUP ATTACKER
-----------------

Attacker adalah mesin lain yang mengirim trafik serangan ke broker.

Project legacy ini tidak mengatur script attacker utama di root. Pada skenario
DoS, serangan dijalankan dari mesin attacker sesuai alat uji yang diizinkan.

Catatan:
Serangan hanya boleh dilakukan pada testbed sendiri atau lingkungan yang sudah
mendapat izin.


4. JALANKAN SKENARIO NORMAL
---------------------------

Pada PC A:

./run_all_cli.sh

Isi:

- IP broker MQTT;
- interface PC A;
- port MQTT.

Pada skenario normal, attacker tidak dijalankan.

Setelah cukup data:

Tekan CTRL+C.

Output:

- logs/mqtt_1883_probe_log.csv
- pcap/mqtt_traffic_<timestamp>.pcapng
- pcap/mqtt_traffic_<timestamp>_raw_flow.csv


5. JALANKAN SKENARIO DOS
------------------------

Pada PC A:

./run_all_cli.sh

Setelah sniffer dan prober berjalan, jalankan trafik serangan dari mesin
attacker menuju broker MQTT.

Setelah cukup data:

Tekan CTRL+C di PC A.


6. JALANKAN SKENARIO DOS + RATE LIMITING
----------------------------------------

1. Aktifkan rate limiting pada sisi broker atau perangkat mitigasi.
2. Pada PC A jalankan:

   ./run_all_cli.sh

3. Jalankan trafik serangan dari mesin attacker menuju broker.
4. Setelah cukup data, tekan CTRL+C di PC A.


7. EKSTRAKSI MANUAL JIKA DIPERLUKAN
-----------------------------------

Jika raw_flow.csv belum terbentuk otomatis:

./extract_raw_flow.sh pcap/NAMA_FILE.pcapng


8. HITUNG METRIK
----------------

python3 compile.py pcap/NAMA_FILE_raw_flow.csv -o metrics.csv --ports 1883


9. VALIDITAS DATA
-----------------

Karena sniffer berada pada PC A, pastikan interface yang dipilih memang melihat
trafik yang ingin dianalisis.

Jika trafik attacker menuju broker tidak melewati PC A, maka capture PC A tidak
akan merekam serangan secara lengkap.
